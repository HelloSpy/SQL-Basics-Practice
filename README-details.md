# SQL basics Practice
A foundational SQL repository containing database schemas, sample data insertions, and basic query operations for testing structural logic.
## 🛠️ Tech Stack & Environment
* *Language:* Structured Query Language (SQL)
* *Target Systems:* MySQL, PostgreSQL, MS SQL Server, or any standard RDBMS

## 📊 Database Structures

### 1. Employee Database (abc)
Contains basic structural data for corporate staff records.
* Emp_id (INT, Primary Key)
* Name (VARCHAR)
* Salary (INT)

### 2. Student Database (college)
Tracks academic performance metrics across geographical locations.
* Roll (INT, Primary Key)
* Name (VARCHAR)
* Marks (INT)
* Grade (VARCHAR)
* City (VARCHAR)

## 🚀 Key Queries Demonstrated
* Basic operational selection (SELECT *)
* Filtering datasets using conditional logic (WHERE, AND, >)
* Eliminating duplicate record outputs (DISTINCT)
